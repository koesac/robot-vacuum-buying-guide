# UK Robot Vacuum Buying Guide

A static, mobile-first buying guide with model comparisons, ownership scenarios, home-fit questions, UK purchase links and video reviews.

## Deployment status

The HTML guide must be committed as `index.html` before deployment can succeed.

In repository Settings > Pages, choose **GitHub Actions** as the build and deployment source. This workflow does not enable Pages automatically. After the HTML is committed and Pages is configured, run the Deploy guide to GitHub Pages workflow or push to main.

The intended site address is https://koesac.github.io/robot-vacuum-buying-guide/ . It is not confirmed live until a successful deployment.

## Data and privacy

Prices and product details are a research snapshot dated 2 November 2026, not live offers. Verify retailers, exact model variants, stock and prices independently.

The guide stores entered notes and selections in the visitor's local browser storage. Embedded YouTube videos contact YouTube only when loaded.
